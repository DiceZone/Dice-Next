## 当前进度

### 待发布（2026-10-09）：Linux/macOS 完整自动更新

- 新增轻量 POSIX 前台管理器，`start.sh` 启动它而不是直接执行核心。等待核心退出后安全替换程序、依赖和内置资源，配置、数据库、用户牌堆及非内置插件不参与覆盖。
- 复用立即安装、定时安装与重启安装授权；管理器自身也会重新执行，保留 PID、工作目录和原参数。直接核心的普通重启改为 exec，并在 exec 时释放实例锁。
- gzip/tar 解包限制大小和条目数，支持 PAX/GNU 长名称与库内符号链接；拒绝目录穿越、重复文件、硬链接和特殊文件。替换前检查核心及管理器加载能力，事务日志支持替换失败与中断恢复；不回滚数据库或绕过 Gatekeeper。
- 本地 macOS 更新专项 48 用例 / 376 断言及进程冒烟通过；Linux/macOS 发布流水线补充轻量进程冒烟。完整发行包跨版本实机验收与 Linux 运行结果仍需另记，不视为已发布。
- beta.928 及更早的 Linux/macOS 包需手动完整覆盖一次；以后通过 `start.sh` 或 `dice-next` 使用安装功能。容器仍仅检查通知，走镜像升级。

### 定时安装更新

- Windows 管理器模式下可先下载并校验更新包，按服务器时区定时安装，默认 04:00；面板显示实际计划日期与时区。
- 暂存包与计划在重启后保留；自动安装开启时，任何提前发生的重新启动都会安装就绪包。定时只限制程序主动重启；切换为仅下载 / 仅通知会撤销启动时安装授权，手动安装可立即执行。
- 新下载包由启动器安装门闩保护；中断 / 取消的准备不会在下次启动时自动排期，同一暂存版本不重复下载。

### 已发布（build 926）：概率文案与多人格

- 指令和人格条目支持多条候选的增删改、整数权重和实际概率；兼容旧版 sample，并允许候选中嵌套 sample。
- 预览与实际发送共用候选选择和 sample 渲染，支持重新抽取；每条 Markdown / 纯文本版本保存时缓存。
- 全局人格池按权重选择，一次指令保持同一人格；群、私聊和账号固定选择继续优先。重启、删除、切回单人格及导入导出均有验证。
- 本体与 WebUI 需同步升级；新版前端不会向不支持的旧后端保存原生概率模板。build 925 及之前不包含此功能；验证范围见本轮检测报告。

### 已发布（build 926）：启动目录保护与托盘提示

- Windows 启动器与核心在写入日志、配置及数据库前检查程序目录和实际运行目录；临时目录启动会被拒绝并提示先完整解压。
- 基础设置支持全局自定义 Windows 托盘名称，最多 10 个 Unicode 字符，保存后立即生效；留空恢复默认，自动追加实际监听端口。

### 已发布：Release 缓存与编译提速

- 修复 runner 环境升级后依赖缓存反复重编、无法保存新结果的问题；改为有条件刷新的二进制包快照。
- 发布构建不再附带测试程序；新增 Windows / Linux 后端测试门禁，配合受控的 MSVC 文件级并行。
- 本地验证结果及首次缓存预热说明见 [Release 构建](ci-release-build.md)。

### 已发布：旧 Dice! Mod 兼容子集（持续完善）

- 恢复全局 `.mod` 管理语义、常见 TOML 回复与周期事件；补齐变量条件、团务集合、帮助模板和旧模组加载顺序。
- 启停模组时同步刷新 XML 模板，保留 SeaDice JS 与旧 Dice! Mod 的体系边界。
- JS 使用海豹体系，不做旧 Dice! JS 兼容；Python 暂不纳入计划。Lua 的 clock/hook、嵌套模组及复杂规则仍有边界，详见 [兼容修复与已知边界](legacy-mod-compatibility.md)。

### 已发布：旧版随机文案兼容

- 补齐 `{sample:甲|乙}`，用于掷骰等指令回复、人格文案、自定义回复和 `.text`；支持等概率选择、嵌套分项及当前入口已有变量，保留自定义回复的 `{甲|乙}` 简写。
- 在变量插入前抽取，只执行选中的分项；保留 Markdown 纯文本预转换，文案抽样不使用游戏骰点随机源。
- 相关修复已随后续 Release 发布；build 909 及之前不包含此语法。只处理选中分项，不改变游戏骰点随机源。

### 已发布：BDC 云人物卡与云服务

- 对接 BDC `b894848` 的设备码授权与云人物卡 API，新增私聊 `.cloud` 授权、列表、拉取、上传、同步及本机退出授权（`.pc cloud` 为等效旧拼法）。
- 默认只读，写入需玩家显式申请并在账号站同意；正式骰娘 Key 按适配器读取，临时凭据按骰娘账号和玩家隔离，不写普通日志或磁盘。
- 保留本地人物卡作为运行基础，以原始属性、文本、锁定和插件扩展字段进行转换；稳定卡 ID 映射支持本地改名，拒绝覆盖同名/有改动的本地卡和歧义旧数据。
- 使用 `base_rev` 接受 BDC 三方合并，409 停止且不强制重试；后台有界队列避免阻塞普通掷骰线程。
- 当前为手动同步，BDC 设备令牌无续期接口，过期/重启需重新授权；使用说明与协议边界见 [云人物卡](cloud-cards.md)。
- WebUI 提供独立的云服务页，集中管理骰娘密钥、心跳、云黑名单、云人物卡与日志站；图床仍在基础设置，适配器原密钥入口保留。详见[云服务设置](cloud-services.md)。

### 已发布：分群功能开关

- 当前版本提供 `.bot log/reply/roll/plugin on/off`，分别控制日志、自定义回复、内置投掷和插件；聊天与 WebUI 共用设置，按群及骰娘账号隔离。
- **总开关仍有效**：`.bot off` 或日志功能关闭会停止日志写入及计时，不删除记录、不结束会话。重新开启后仅恢复原本进行中的日志，用户手动 `.log off` 的暂停状态保留，关闭期间消息不会补录。
- “只记日志”：保持 `.bot on` 与 `.bot log on`，关闭 roll、reply、plugin；AI、欢迎语、转发和自动化按需要另行关闭。这不是禁用所有非日志指令的专用模式。
- 9 月 7 日的 off 下独立记录方案已于 9 月 8 日被本方案替代；普通 off 时不再把 `.log`、`.reply` 作为绕过总开关的例外。
- `.master` 兼容已支持的管理操作，未兼容的 reset/delete/groupclr 等会明确提示。彻底禁用、黑名单、既有权限及原有明确 @ 唤醒规则不被子开关绕过。

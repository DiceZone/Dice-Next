# 旧版 Dice! Mod 兼容修复记录

本轮为本地待提交改动，不表示已发布，也不表示整个旧版 Mod 运行时已完整复刻。旧 Dice! Mod 与 SeaDice JS 插件是不同体系，不能互相替代。

## 本轮修复

- `.mod` 恢复全局模组管理入口：列表、详情、启停、重载、删除；要求 Master 或信任等级至少 4，普通群管理员不能修改全局模组。兼容 `.mod on 名称` 与 `.mod 名称 on`。`.plugin` 保留分群启停语义。
- 目录型 Mod 支持常见 `reply/*.toml` 声明：匹配方式、规则限定、Lua 动作、静态文本、冷却以及用户/群变量比较。解析器是兼容子集，不是完整 TOML 实现；无法处理的限制会记录警告并跳过该回复。
- Lua 回复识别 Match/Prefix/Search/Regex 大小写拼法。Regex 改为整条消息匹配、忽略大小写、保留量词，并沿用旧版 400 字节输入上限。
- `user_var.xxx=true` 按旧版真值判断：已有文本、数字 0 都可通过；缺失值和布尔 false 不通过。支持 equal、neq、at_least、at_most、more、less；trust 使用当前请求的信任等级。
- `type="Game"` / `rule` 通过当前团务和参与者检查；团规则优先于普通回复。当前规则名支持精确匹配及父规则前缀匹配。
- `event/*.lua` 的正数 `trigger.cycle` 配合 `action.lua` 支持立即执行、周期重排；重载后旧回调失效。支持 second/minute/hour/day 单位。
- `msg.game.pls/gms` 恢复集合读取、添加和删除持久化；布尔配置写入不会被当作删除，GameTable 读取 false 不再变成真值字符串。
- `{help:主题}` 可读取活动模组帮助并回退到核心帮助查询。
- 导入旧版 `conf/ModList.json` 的启停状态和顺序；目录型和描述文件型 Mod 统一排序，同名 reply ID 后加载覆盖前面。不覆盖导入时保留已有文件和已有顺序文件。
- 禁用的 Mod 目录不再贡献 XML 模板；聊天命令和 WebUI 启停、删除、导入、重载后都会刷新模板。XML 别名及简单派生公式原本已有实现，本轮不是重新实现整套 XML 引擎。

## 回归覆盖

2026-09-27 本地 Windows Release 验证：完整编译通过；Lua 自包含测试 13 项、151 条断言通过，另有 2 项外部语料测试因未提供路径而跳过；Mod 导入 4 项 / 18 条断言及 `.mod` 管理 1 项 / 9 条断言通过。

全量核心测试运行 465 项，共 2962 条断言，2961 通过、1 失败：`PersonaPermission.PrivateSelectionIsPersonalAndNeverChangesGlobalPersona` 中 `.rpmode inherit` 返回值未包含“基础”。该断言在本轮收尾前已出现，未修改人格逻辑或放宽断言；因此全量 CTest 不是全绿。

自包含用例覆盖 TOML / Lua 回复、变量真值与数值比较、整条正则与长度限制、团规则优先级、帮助模板、玩家集合、事件重载、混合模组顺序、禁用后的覆盖回退、导入启停状态，以及 `.mod` 权限与动作分发。

同时保留已有单文件 Lua、相邻资源加载、定时任务、编码和异常保护回归。外部用户插件语料测试需要显式提供环境变量，未提供时会跳过，不能把自包含测试通过等同于全部用户插件已通过。

## 已知边界 / 后续待做

- 旧 Dice! 的 `echo.js`、Python 动作尚未接入；尤其 BRP 的部分 team 动作是旧 JS，不能因 TOML 可读就宣称可用。SeaDice JS 引擎不等于旧 Dice! JS API。
- clock/hook 事件、完整 rulebook/tape 行为尚未复刻。
- 包装目录内的嵌套 Mod（例如命名空间/子模组）尚未完整发现和管理；不要直接递归执行所有资源 Lua。
- TOML 多行字符串、复杂表、完整条件语法仍有缺口；Lua 声明也不等于完整旧版条件系统。
- 配置数据库仍按字符串保存，无法无损区分字符串 "false" 与布尔 false、数值字符串与数值、空串与缺失值。
- Regex 仍使用字节字符串实现，中文字符类、点号和捕获索引与原版宽字符实现可能不同；输入长度限制不是正则执行时间限制。
- XML 复杂脚本派生值、模组模板覆盖顺序、全局脚本命名空间、全部回复触发优先级仍需专项对照；不能宣称任意旧模组开箱即用。
- `.mod get/update/reinstall` 仅提供 WebUI 管理提示，没有恢复旧远程下载器。

# 旧版 Dice! Mod 兼容修复记录

## 2026-10-19：便利功能安全兼容（main）

- 普通文案、自定义回复、文件牌堆与 Lua speech 共享 sample / case / grade、整数 ran、len、过期检查 expired、局部 var、受控 at 与身份 print；不执行模板脚本或阻塞线程。插入字段不再次解析，转义字段也不被最终插值二次替换。
- len 支持 Lua Set / 普通表的有界元素计数，以及原生当前团的玩家 / GM 人数；数字型和字符串成员 ID 都可识别。print 补齐当前消息、骰主、自身及指定 ID 的名称展示，只读当前平台、账号的数据和缓存，不临时联网或借用其他账号。
- `msg:format/get/echo` 读取本条消息的标量及受控点路径，拒绝内部字段和函数；返回回复与协程恢复路径保留 false 与嵌套数据。局部模板变量不写人物卡、用户配置或权限，插入的数据不再次解析。
- 导入的自定义帮助、文件与文档包补齐多级 `&主题`，遵守查询语言、优先来源和搜索域，并限制循环深度。动态资源目录增加 JS 命令快照和 Lua 静态变量条件；查询不获取脚本运行时锁，不调用 getter / Proxy，不消耗规则计数。需执行动态键或读取 SelfData 文件的条件仍保守隐藏。
- `.deck session range <名称> <起点> <终点> [正步长]` 和 `.deck session members <名称>` 新增整数范围与当前账号群成员快照，不改 `.deck set`。保留团务和管理权限、数量限制及保存失败保护；生成牌面为字面文本，不执行昵称里的模板或份数标记。
- 文件牌堆使用单次渲染的写时复制目录快照，共享模板工作量上限，保留权重、子牌池、媒体和转义；不持有目录锁调用宿主。显式骰子块在插值前识别，不把昵称中的方括号当骰子再次求值。
- wait 改为有界异步回复计划或 Lua 消息协程，预览不等待；原生待发最多 256 条 / 16 MiB，单条累计至多十分钟。结果入队前确定，发送前复查权限和来源连接；更换账号、相关群插件 / 回复 / 规则权限变化、插件重载或退出取消旧等待，不延后已执行的管理动作。
- 本轮没有恢复任意虚拟消息提权、模板内 JS / Python、宿主配置穿透或旧式阻塞 wait。端到端平台投递仍需另行验收，不能由离线回归推断任意旧插件均可运行。
- 最终验证范围见[测试记录](../server/tests/TEST_REPORT.md)；不能把离线测试当作真实平台投递或全部旧插件运行保证。

旧 Dice! Mod 与海豹骰（SealDice）JS 插件是不同体系，不能互相替代。本页按日期记录实现与验证范围，所用安装包以对应 Release 的源码版本为准，不将“发现了目录”视为“整包全部可运行”。

## 2026-10-15—16：安全兼容补齐（本地实现）

- **TOML 与回复动作**：使用 toml++ 解析多行字符串、引号键、嵌套表、内联表及数组；支持空回复、文本候选、`::权重::` 与嵌套 sample，以及 Lua 函数、脚本名和内联 Lua。含未知条件或混合不支持动作的条目会跳过并报告原因，不放宽成无条件触发。
- **条件系统**：补齐 `prob`、用户 / 群 ID 正反名单、`self_var`、`user_var`、`grp_var`、共享冷却、每日限次、同步锁和 `dicemaid`。标量冷却按聊天窗口计算；可指定 user / chat / global 范围及共享名称。每日计数持久化，按服务器时区换日；锁等待非阻塞、有界，延时、出错、重载及卸载均释放或取消旧任务。
- **类型与权限**：沿用类型编码保存字符串、布尔、数字、空串与集合，不把文本 `"false"` 当布尔 false；旧真值规则中仅缺失值与布尔 false 为假。比较条件使用实际信任等级，机器人身份来自宿主名单，不相信用户文本伪造的身份。
- **定时与事件**：`cycle` 支持 1 秒至 7 天，加载后立即执行一次再重排；`clock` 支持时 / 分及列表，按服务器时区执行。接入 `StartUp`、`DayEnd`、`DayNew`、`Message`、好友 / 群请求与通知、戳一戳及 `LogEnd` 等安全钩子；重新加载不会冒充程序启动，旧回调会失效。
- **宿主控制**：消息 / tape 继续遵守禁用、黑名单、分群插件开关和内容拦截，不吞掉凭据 / 恢复管理指令。请求钩子可以拒绝，不能越过宿主策略自动批准；钩子执行失败会留下待处理请求，而不是自动同意。`LogEnd` 仅提供受控日志路径与默认上传控制，不恢复任意文件发布。
- **规则书与 tape**：支持规则手册的继承、当前规则优先和命名主题查询；只在活动团务、成员及分群开关允许时执行对应 tape。
- **目录与加载**：发现、启停、删除嵌套命名空间模组，保留父级禁用；递归读取资源并统一脚本命名空间、后加载覆盖。同名目录与单文件插件使用独立管理 ID，避免误删。兼容中文目录，拒绝路径穿越、符号链接及 Windows 联接，不把资源目录里的任意 Lua 自动当入口执行。
- **回复优先级**：活动团规则优先，然后是 Match、最长 Prefix、Search、Regex；同级目录模组按加载顺序覆盖，旧单文件插件保留自身匹配习惯。空回复或只产生副作用的动作同样标记为已处理，不再落入 AI / 自定义回复兜底。
- **XML 属性**：支持属性别名、CDATA、基本实体和安全数值公式；公式支持四则、比较、短路、三元、属性默认值与白名单数学函数。仅解析数据，不执行 XML 中的 JavaScript。模板按模组顺序加载，停用或重载同步刷新，原生规则包优先级保留。
- **异步与多帐号**：Lua 函数可以暂停续跑；保留触发平台、适配器帐号、消息上下文和日志来源。已知帐号离线时不把消息转发给另一帐号，重载和销毁后不会继续执行旧回调。`require('Set')`、`Actor`、`GameTable`、`SelfData` 公共别名补齐。
- **自身帐号身份**：`getDiceQQ()`、`self_var` 和骰娘身份条件跟随触发适配器；延时 / 事件恢复时同样解析对应帐号。已知帐号身份缺失时不借用全局或另一帐号；仅无帐号上下文时保留旧全局配置兜底。
- **Session 私有牌堆**：三参 `drawDeck(gid, uid, name)` 和原生 `.draw` 共用团务不放回牌池，抽空不回退同名公共牌堆；跨接入群共用剩余数量，不同 Session 独立。保留旧 `meta / idxs / size` 存档及已抽顺序，重复导入默认不补牌，保存失败不扣牌。早期已归档的合法 `__legacy_decks` 可按需启用；非法状态保留并诊断，不伪装成完整导入。
- **牌堆入口与日志字段**：新增 `.deck session help` 下的新建 / 复制 / 余量 / 重置 / 删除管理，仅本团 GM、群管或骰主可修改；Next 原有 `.deck new/set/del/clr` 群临时牌堆与默认牌堆含义不变。`LogEnd` 提供实际导出文件名 `log_file`、路径、日志名、条数和触发来源，普通 `.log end` 与 `.game over` 均先关闭 / 结算再调用，钩子在团务锁外执行。
- **speech 与脚本生命周期**：词条键按旧版忽略 ASCII 大小写，YAML / JSON 的文本数组每次均匀抽取，不再忽略或只取首项；别名、嵌套变量和模组覆盖同样适用。目录文件 / 文本脚本的临时全局变量按次隔离，`loadLua` 子脚本仍共享当次环境，交错延时与事件不串临时变量；`eventMsg` 重入后恢复外层消息，不再借用内层的昵称、用户 ID 或变量。已登记函数保留 Next 的闭包能力，不做通用 LuaState 克隆。
- **脚本名与帮助**：脚本名 / 帮助主题忽略 ASCII 大小写并按 Mod 加载顺序覆盖；`script/foo/init.lua` 可用 `foo` 调用，保留 Next 的 `foo.init` 写法。帮助列表、跨 Mod 多级别名和 `{help:主题}` 使用同一合并命名空间。`.help` 和自定义回复的帮助引用仅渲染选中的条目，支持消息变量、speech、sample 和其他帮助引用，不提前渲染整个帮助库，也不改动原有内置 / JS 优先级及搜索域过滤。

### 不等于任意旧包无损复刻

- JS 仍使用海豹体系，不执行旧 Dice! 的 JS / Python 动作、外部 Lua 字节码或任意 XML 脚本；不恢复旧远程下载安装器及授权 / 审查策略覆盖钩子。
- 多个比较操作同时声明时要求全部满足；不会复制旧实现只采用部分比较项的宽松行为。
- cycle、clock、启动 / 日界动作可暂停续跑；即时消息、审批、通知和 tape 钩子同步处理，`sleepTime` 不会延迟宿主决策或阻塞消息线程。
- Dice!Next 保留一次消息选择一条回复的分发方式，不复制旧版多个 Regex 同时连续发言的行为。内置管理指令、分群总开关及权限不能被模组绕过。
- 正则为有执行时限的 ECMAScript `i` 整条匹配；旧 Mod 的 400 **字节**上限仍保留。非 `u` 模式按 UTF-16 单元计数，不承诺 C++ locale / POSIX 扩展等价。详见 [正则检测记录](regex-compatibility-report.md)。
- XML 转换器只读取属性数据与安全数值表达式，不是通用 XML / JavaScript 引擎；无法转换的派生值在兼容性诊断中说明。没有原生入站事件的平台不会凭空生成对应钩子。
- 一参 `drawDeck(name)` 继续抽公共牌堆；三参优先读取所在活动群 Session 的私有牌堆。群临时牌堆、群默认牌堆与团务牌堆分层管理，不改写 Next 原有指令的含义。原本无法定位群的私聊 / 频道旧团务仍不自动启用；`LogEnd` 虽补齐常用字段，但不承诺整个旧日志 / Session 对象逐字段等价。
- 加载、资源和队列有深度 / 数量上限。实际社区插件仍需带样本验证；本地模拟通过不能代替真实帐号投递验收。
- 模板展开最多 24 层、10,000 次变量 / 引用解析，单次结果最多 4 MiB，嵌套中间文本累计 32 MiB；超过大小 / 工作量限制返回空文本，避免循环或分叉引用耗尽内存。纯图片 URL / CQ 引用不受资源文件体积影响，但模板内直接嵌入的大段 Base64 同样计入文本限制。

### 真实语料追加验收（2026-10-16，本地）

追加验收实际启用四组外部语料：ResourceSearchEngine（详情与重载）、求签 / DailyNews（七类签、动态新闻与定时入口）、旧官方 `PC_Inventory`（背包增删查）、`PC_Slots`（数量物品、状态、法术、专长和笔记）。完整 Lua 运行 **54 用例 / 571 断言**通过，包含 50 个自包含用例与 4 个真实语料入口；不是在上一组 Lua 数字上累加。最终 Windows Release 主程序编译及核心 **734 用例 / 48,874 断言**通过，文档校验与构建通过；Linux/macOS 和真实帐号投递仍未验收。

原样本只读复制，测试网络 / 发送 / 定时入口使用受控替身，文件读写限于无链接的测试副本，进程与原生库入口被禁用。这是已审查样本的测试防护，不是可运行任意恶意 Lua 的操作系统沙箱，也不代表真实适配器投递验收。真实样本复现后修复了 speech 大小写 / 数组缺口；独立合成用例在修复前复现脚本变量串用，再验证同步、事件及交错续跑。

样本自身的问题不由宿主篡改脚本“修好”：例如本地 `PC_Slots/script/reply_inventory_del.lua` 从消息解析 `name` 却读取 `list[item]`，删除物品存在源代码错误；验收包含正常的 `物品-名称` 路径，不为错误脚本恢复跨指令变量污染。两套背包 Mod 的同名词条 / 回复也不应当作互不相关的功能同时加载。

### 脚本名称与原生帮助追加验收（2026-10-16，本地）

修复前的独立用例复现了大小写脚本覆盖错误、目录 `init.lua` 缺少包名入口和帮助查找 / 别名不一致。修复后，原生帮助桥接测试同时检查选中条目上下文、内置 / JS 优先级、搜索域和自定义回复中的帮助引用；真实 Lua 检查消息变量优先、跨主题 / speech / sample 引用、循环 / 分叉 / 超大输入及后续恢复。

最终 Windows amd64 Release 编译通过；核心 **735 用例 / 48,885 断言**、Lua **58 用例 / 612 断言**通过，后者包含 54 个自包含用例和 4 个实际启用的外部语料入口。不启用外部语料时为 528 断言，4 个入口会提前返回，不能算作真实插件覆盖。文档校验及文档站构建通过，原插件样本未修改；尚未提交 / 推送 / 发布，Linux/macOS 与真实帐号投递仍未验收。

## 先前已发布的基础修复

以下修复由 `13f3ba1` 合入并随后续 Release 发布（截至 2026-10-03 的 beta.925 已包含）。这是历史范围说明；其受限解析和事件缺口已由上面的本地实现扩展。

- `.mod` 恢复全局模组管理入口：列表、详情、启停、重载、删除；要求 Master 或信任等级至少 4，普通群管理员不能修改全局模组。兼容 `.mod on 名称` 与 `.mod 名称 on`。`.plugin` 保留分群启停语义。
- 目录型 Mod 支持常见 `reply/*.toml` 声明：匹配方式、规则限定、Lua 动作、静态文本、冷却以及用户/群变量比较。当时使用子集解析器；无法处理的限制会记录警告并跳过该回复。
- Lua 回复识别 Match/Prefix/Search/Regex 大小写拼法。Regex 改为整条消息匹配、忽略大小写、保留量词，并沿用旧版 400 字节输入上限。
- `user_var.xxx=true` 按旧版真值判断：已有文本、数字 0 都可通过；缺失值和布尔 false 不通过。支持 equal、neq、at_least、at_most、more、less；trust 使用当前请求的信任等级。
- `type="Game"` / `rule` 通过当前团务和参与者检查；团规则优先于普通回复。当前规则名支持精确匹配及父规则前缀匹配。
- `event/*.lua` 的正数 `trigger.cycle` 配合 `action.lua` 支持立即执行、周期重排；重载后旧回调失效。支持 second/minute/hour/day 单位。
- `msg.game.pls/gms` 恢复集合读取、添加和删除持久化；布尔配置写入不会被当作删除，GameTable 读取 false 不再变成真值字符串。
- `{help:主题}` 可读取活动模组帮助并回退到核心帮助查询。
- 导入旧版 `conf/ModList.json` 的启停状态和顺序；目录型和描述文件型 Mod 统一排序，同名 reply ID 后加载覆盖前面。不覆盖导入时保留已有文件和已有顺序文件。
- 禁用的 Mod 目录不再贡献 XML 模板；聊天命令和 WebUI 启停、删除、导入、重载后都会刷新模板。XML 别名及简单派生公式原本已有实现，本轮不是重新实现整套 XML 引擎。

# 云服务设置

WebUI 的统一入口为 **系统设置 → 云服务**（`#/cloud-services`），
与侧栏的 **基础设置**、**通知设置** 同级，不是基础设置页面内的页签。
本次调整只迁移界面，不改变配置文件格式和已有的服务开关，无需重新填写配置。

## 集中管理的内容

- **骰娘密钥配置管理**：按适配器分别设置、替换或清除骰娘 API Key。
  适配器页原入口保留，两处使用同一适配器保存接口、同一份持久化配置。
  云服务页仅提交 `heartApiKey`，不提交旧的连接参数或启用状态；
  留空不修改，明确选择清除后再保存才删除密钥。现有密钥仅显示末四位。
- **云人物卡**：集中说明接入条件及玩家授权、同步方法；不新增另一份密钥。
  个人授权、查询和同步仍通过玩家私聊中的 `.pc cloud` 指令管理。
  后台不展示玩家授权码或令牌，也不代替玩家同意授权。
  详见 [BDC 云人物卡适配](cloud-cards.md)。
- **云黑名单**：原权限页的云黑名单入口改为跳转到此处。
  保留同步开关、地址、独立 Token、自动上报、危险等级、同步间隔、
  最近同步结果及立即同步。权限页的本地黑名单管理和云黑标记不变。
  未设置独立 Token 时，沿用原有规则：兼容旧心跳 Token，再回退到任一适配器的骰娘 Key。
- **心跳**：保留服务开关、地址、骰主信息、公开展示、上报间隔、
  最近状态及立即测试。密钥统计使用与适配器共享的最新配置状态。
- **日志站**：迁入原地址、上传协议、恢复默认配置入口。

图床不属于 BDC 云服务，仍在 **系统设置 → 基础设置** 的数据与图片区域；
保留全局、适配器类型和具体账号的覆盖与重置机制，配置值不变。

人工智能、程序更新和通知管理仍属于各自独立功能页面，不因使用网络而并入公共云服务配置。
WebUI 管理 API Key 也不是骰娘云服务 Key，仍位于 WebUI 设置。

## 搜索与兼容

全局搜索将云服务相关条目定位到独立云服务页面，将图床定位到基础设置。
旧的 `#/settings?tab=cloud` 和 `#/settings?focus=settings-heartbeat` 等链接仍可进入云服务页面。
旧的图床搜索链接即使包含 `tab=cloud` 也会回到基础设置。

## 验证范围

前端包含密钥更新、共享适配器状态、失败回退、搜索链接、四种语言文案、
实际 React 渲染及原接口保留的回归测试。
可在 WebUI 仓库运行 `npm test` 和 `npm run build`。

隔离预览：构建后运行 `node tests/preview-cloud-settings.mjs`，
访问 `http://127.0.0.1:43129/#/cloud-services`。
此预览仅使用内存中的虚拟数据，不连接真实骰娘，也不向云端发送请求。

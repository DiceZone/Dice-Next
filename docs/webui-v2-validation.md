## 同步修复与依赖

旧黑名单数组的 `entries` 会命中 `Array.prototype.entries`，误当 React 状态回调，现已在两个 UI 中安全区分数组与包装响应。服务器 OS 图标、登录和侧栏图标改为版本目录内相对地址；首页读取失败保留最后真实快照并提供重试。

V2 使用独立依赖目录和锁文件，不共享 V1 的 node_modules。修复了审计发现的 Zod、Seroval 及构建工具依赖风险；Typography 的旧解析器固定到兼容 API 的 `postcss-selector-parser` 7.1.7，并通过完整编译与页面回归。没有执行自动 `audit fix` 或关闭 TLS 校验。

Tremor 原始来源、固定提交与 Apache-2.0 许可证，shadcn CLI 来源与 MIT 许可证均有记录，并随 V2 输出到 `licenses/`。React Bits / Skiper 不是强制运行依赖，未复制许可不明确或带额外限制的素材。

## 边界

这是 V2 首个可用预览版验收，不是宣布稳定版。浏览器测试使用隔离内存 API，未向真实群聊发送消息，不替代每个协议端的实机联调。本轮未执行 GitHub Actions，未声称五个平台已编译或发布；CI 与打包逻辑已更新，但必须先将两套 UI 分支和主程序改动按依赖顺序提交、推送，才可用于远端发版。

V1、V2 及文档构建仍有原项目体积警告；V2 已拆出页面，但包含四语言文案的入口仍较大，未通过放宽警告阈值掩盖。后续若继续优化语言资源加载，仍需保持首次语言选择及离线行为。

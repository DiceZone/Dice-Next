# 图片资源与牌堆打包

入口：**数据管理 → 文件管理 → 图片资源**。列表只读取路径、大小、修改时间等元数据，不请求图片内容；点击某行的「预览」才加载那一张图片。上传、预览、下载与管理接口均沿用 WebUI 登录 / API Key 鉴权。

## 目录归属

所有新上传图片位于本实例的 `data/images/`。目录用于整理归属，不限制引用位置；回复也可以引用牌堆目录或自建目录中的图片。

```text
data/images/
  reply/                  自定义回复
  text/                   掷骰文本与人格文案
  deck/塔罗.json/cards/    按牌堆文件名集中存放，保留子目录
  plugin/旅途助手/         按插件名集中存放，保留子目录
  mod/自定义规则/          按模组名集中存放
  chat/                   主动上传的聊天图片、表情收藏
  shared/                 通用资源
  cache/chat/             有保留期的聊天缓存
  cache/log/              跑团日志图片缓存
  自建目录/               用户自由整理
```

不是全局哈希池：相同图片不会因为去重而被拆离所属牌堆 / 插件。一个文件被多个独立来源使用时，可以保留各自归属副本。

## 操作与引用

- 支持服务端分页、名称 / 路径搜索、排序、新建目录、批量上传、下载、复制、剪切、粘贴、重命名、回收与恢复。
- 每张图片都有独立的「预览」「复制图片代码」按钮。图片码为 `[img,file=data/images/…]`，逗号、方括号、`&` 使用 CQ 参数转义。
- 回复、掷骰文本、人格、牌堆、插件模板配置、模拟聊天共用图片选择器。选择已有资源不会再次上传或读取图片内容。
- 目录和批量选择支持 ZIP 下载；图片 ZIP 导入保留目录结构，只接收支持的图片。覆盖同名文件必须确认。
- 移动 / 改名先复制并校验图片，再以「原值仍一致」为条件保存已识别引用，最后退役旧路径。旧图片码、旧资源 ID 和已有公开 token 通过别名兼容。
- 引用索引检查声明的数据字段和文件，不运行插件、模板或骰子表达式。发现仍被引用的图片时拒绝删除；扫描失败时也不把资源当作未使用。
- 插件动态拼接、外部数据库或任意脚本 IO 无法静态保证穷尽。未发现引用不代表一定闲置；请优先回收，不要直接永久删除。

普通预览不生成公开链接。只有明确配置 HTTP 图片发送或调用分享入口时，才为永久资源创建随机 token 链接；聊天和日志缓存不能通过资源分享入口公开。

## 迁移与恢复

启动后在后台整理已有 Next 图片目录。旧 Dice! 导入时，能确定的牌堆图片直接复制到 `data/images/deck/<导入后的牌堆文件名>/`，并修改 Next 中的牌堆引用。旧骰子源目录只读，不修改源牌堆或插件。

插件 / 模组的私有图片树按归属整体归档；不自动改写 Lua / JS 源码。已登记图片路径的 Lua `io.open` 读写会映射到受管资源，普通文件 IO 保持原有逻辑。无法证明可删除的旧私有路径保留兼容副本，避免目录枚举、动态路径和未识别调用失效。迁移警告可在文件管理查看，必要时手动重新扫描。

回收文件可恢复；永久删除需要再次确认。多文件移动保留操作日志与覆盖前副本；异常重启只恢复可证明未被后续修改的内容，否则保留两个位置并报告待处理项。

备份保留资源文件和 SQLite 索引快照。局部备份按分类筛选资源，局部恢复合并索引，不覆盖未选择资源的路径别名和公开 token。缓存仍遵守原保留期 / 日志删除规则，不与永久资源混为一类。

## `.deck` 包

WebUI 导出含本地图片或已知跨文件牌堆依赖的牌堆时，生成海豹兼容布局的 `.deck` ZIP；无本地依赖时仍提供 JSON。

```text
塔罗.deck
  塔罗.json
  依赖牌堆.json           仅在存在可解析的跨文件引用时加入
  assets/cards/a.png
```

JSON 和 `assets/` 直接位于压缩包根目录，不再套额外目录。资源路径改写为 `./assets/…`，中立图片码改写为标准 CQ 图片码。保留权重、转义和嵌套 `sample`，不求值或抽牌。只有静态、已加载且能定位来源的牌堆引用可收集；动态名称或无文件来源的运行时内容不能保证自动补齐。

远程链接不主动下载；本地依赖缺失时拒绝导出残缺包。Next 专有模板语法不会被声称转换为其他引擎的完全等价语义。

`.deck` 导入接受根目录 JSON 与图片；不要求 Next 私有清单或 `info.yaml`。每份牌堆的图片进入自己的文件名目录；未被静态引用的附带图片放入首个牌堆目录并显示提醒。加密包、链接、越界路径、大小写重名、非支持文件和 CRC 错误均拒绝。

限制：上传包 128 MiB、单文件 128 MiB、解压和归档后图片总量 512 MiB、10000 个条目 / 图片、最多 100 个牌堆文件；超过时请拆包。目录内不跟随符号链接或 Windows 重解析点。

## API

- `GET /api/resources/images?directory=&page=1&size=20&q=&sort=name&dir=asc`
- `POST /api/resources/images/upload?directory=reply&filename=a.png`：原始文件字节
- `GET /api/resources/images/content?id=<资源ID或规范路径>`：鉴权读取
- `POST /api/resources/images/folder`、`operation`、`scan`、`share`
- `GET /api/resources/images/usages?path=…`、`GET/POST /migration`
- `POST /api/resources/images/archive`、`extract`：图片 ZIP 下载 / 导入
- `GET /api/decks/export?name=…&source=user|builtin`
- `POST /api/decks/package?inspect=1|0&overwrite=0|1`：`.deck` 原始字节，先校验再确认覆盖

旧 `/api/assets/…`、聊天和日志图片地址仍保留兼容读取，不把文件管理扩展为访问任意宿主机路径的入口。
